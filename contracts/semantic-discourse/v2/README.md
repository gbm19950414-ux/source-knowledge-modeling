# Semantic discourse v2 synthetic contract

`examples/garden.draft.json` extends the v1 community garden source export. It exercises comparison, sequence, explanation and multiple structures across chapter, topic and block scopes, including a support anchor and independent related elements. Its references are synthetic source fields. It is neither a reviewed book model nor a claim of domain advice. The public lifecycle and negative cases are tested in `tests/test_organize_v2.py`.
