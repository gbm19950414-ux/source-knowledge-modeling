# instructional-source@3.0.0

本规范约束来源忠实性和审阅依赖，不判断科学有效性或个人适用性。JSON 配置与本文件原始字节共同组成 `definition_sha256`。执行者先只看来源识别信息和论述，再映射旧模型；审阅者独立查遗漏、擅增、语气、范围和关系依据。

| 规则 | 建模和核对要求 |
| --- | --- |
| IS3-01 来源顺序 | 保存 foundation 的单元 `order` 和每次要素出现的片段位置。来源顺序、内容包顺序、步骤顺序各有不同含义；相邻句不自动产生语义边。 |
| IS3-02 范围 | 主范围逐项审计；上下文只能提供合法证据，不自动计入主范围覆盖。跨段依据标明两端和支撑片段。 |
| IS3-03 信息 | 一项独立含义有语义字段落点或明确缺口。锚点、对象 ID、摘要和任意引用都不能代替“正常”“可能”“不应”等语义判断。 |
| IS3-04 论述 | 分别记录主张、指代、条件、理由、转折、阐释与跨段衔接。每项有关系字段落点，或具体的未明说／未确定判断。无需让整张图连通。 |
| IS3-05 要素 | 每个要素独立判断来源身份、语气、否定、举例范围和量值归属；不能从内容包或旧 statement 批量继承。 |
| IS3-06 关系 | 条件可约束动作或断言；支持表示理由／论据，因果表示来源所述产生机制；对比为无向展示，阐释由细节指向主张。明确规则例外才使用 `exception_to`；限定用 `qualifies`。步骤先后只用 `precedes`。 |
| IS3-07 依据身份 | 关系保存作者表述、作者举例、项目解释或未定身份，并区分明示、由来源充分支持的推断、项目解释和未定。项目解释必须列出前提对象、理由和不确定性，默认阅读层隐藏。审阅接受不改变其来源身份。 |
| IS3-08 证据 | 每个要素和关系绑定冻结来源精确片段／图表原生区域；PDF 核对原页。短引文只在单元内唯一匹配时自动定位，重名须指定起点。证据位置本身不证明语义正确。 |
| IS3-09 审阅 | 来源核验、语义决定和质量报告分别保存真实执行者及输入修订；内容、依据身份、解释前提、上下文或规范改变后重审受影响对象。写草稿不产生接受事件。 |
| IS3-10 迁移 | v1/v2 历史只保留来源与旧审阅事实；继承的要素语气、关系身份和信息落点均待语义复核，不制造新接受。 |
| IS3-11 验收 | 双向检查来源遗漏和模型擅增；字段绑定指向对象的具体语义字段与内容修订。缺口与歧义明确列范围和原因，不靠改成 `uncertain` 回避核心要求。 |

`source_claim` 且 `inferred_from_source` 的关系需要可追溯的原文依据和明确的推理说明。原文只形成共同话题而未给出因果时，记录论述判断，不能编造因果链。关系图默认展示来源层；项目解释层可切换，并保留前提、理由和不确定性。
