# instructional-source@2.0.0

本规范只规定如何保留原文信息、证据与审阅依赖，不判断科学正确性或个人适用性。规则编号稳定；JSON 配置和本指南的原始字节共同组成 `definition_sha256`。以下例子全为合成材料。

| 规则 | 定义与判断问题 | 正例 | 反例 | 实际核对 |
| --- | --- | --- | --- | --- |
| IS2-01 分包 | 内容包围绕一个局部问题或连贯论述；包引用对象，不拥有其身份。是否只是布局移动？ | “灌溉时机”包引用条件和浇水动作。 | 为改标题复制浇水动作。 | 检查包问题、对象引用及跨包关系。 |
| IS2-02 拆分 | 含义需要分别查询、核对或修订时拆成对象；句子不是对象边界。 | “可先浇两次，也可隔天浇”保留两种时间尺度。 | 将不同数值藏在一个不可拆的摘要中。 | 按原文逐项列信息，再比对对象。 |
| IS2-03 身份 | 作者主张、作者举例、项目解释与未解事项分别标记；语气和否定独立于类别。 | “作者举例可能下雨”标为例子、可能。 | 把可能的例子当成必然规则。 | 对照原页的主语、语气词和否定词。 |
| IS2-04 参数 | 数量保存值、单位、基准、对象与适用范围。 | “每盆两升”指向每盆浇水动作。 | 只记“2”或把盆数当水量。 | 逐一核对数字、单位和所修饰对象。 |
| IS2-05 关系 | 关系保存有向端点、作用范围及自己的证据；跨包端点合法。 | “土壤干燥”条件指向“浇水”。 | 因两句相邻就建立先后或因果。 | 分别核对起点、终点、方向及连接依据。 |
| IS2-06 证据 | 来源片段要能回到冻结文字或原页区域；图表须保留原生结构和解释状态。 | 图示未读懂时保留页区与待核项。 | 用图注冒充曲线读数。 | PDF 检查原页，文本检查原件；登记方法。 |
| IS2-07 来源核验 | 来源核验绑定原件、快照、确切片段、方法与真实检查人；不等于语义接受。 | 记录查看了图中哪一区域。 | 因存在字符偏移就写“原页已检查”。 | 核对哈希、片段和方法；来源更新显式映射旧定位。 |
| IS2-08 审阅复用 | 接受决定保持提案粒度，绑定提案内容、规则和上下文依赖；未改对象复用其真实历史。 | 只移动内容包时保留对象内容修订。 | 修改条件后沿用旧提案接受。 | 对比对象和依赖哈希，保留旧事件原粒度。 |
| IS2-09 缺口 | 每项来源信息有模型落点或具体缺口；“未说明”须写已查范围，“不适用”单列。 | “图中第三条线未解释，待原页核”。 | 有锚点便称整句完整。 | 双向核对原文遗漏与模型擅增，记录实际检查范围。 |

阅读分组仅指定标题与有序包引用，不产生知识关系。`conditions` 只记录作者给出的条件约束，不自动变成充分触发的行动规则。旧 v1 提案决定保留为历史来源审阅；迁移不会制造新的逐对象接受事件。
